## Behaviour and invariants

* A real EndTurn request ID is matched to its local turn generation. Failed, unknown, duplicate and superseded acknowledgements cannot clear a new turn.
* A private origin containing generation and authoritative absolute day is captured synchronously in `yourTurn`, before asynchronous work is queued. It is carried through `makeTurn` and `endTurn`; stale queued work is rejected and every submission/retry checks the same origin after waits.
* `startedTurn` is a callback outside CClient's game-state lock. The day guard is necessary: TurnOrderProcessor moves a finished player to `actedPlayers`, and only NewTurn advances the day and recycles that player into `awaitingPlayers`. Simultaneous turns still start each player once per day. Load-resume creates a new session/interface. The caller's shared game-state lock prevents NewTurn's unique-lock mutation between the final day/generation check and actual send. An already-applied NewTurn is rejected even if its startedTurn callback is delayed. Registration alone would be too late to prevent an already sent action.
* An authenticated MoveHero for a real currently owned hero, after that player's authoritative WINNER/LOSER event, receives a typed INFO cancellation and false acknowledgement. No move, MP or object mutation occurs. Inactive INGAME, foreign ownership, unknown connection, unknown/removed hero and owned non-hero requests retain authority errors. Other packet results and diagnostics are unchanged.
* Idle interaction identity is captured before movement: moving hero, destination and sorted target instance/type/subtype/owner. A native prison becomes a hero with the same instance and visitable tile; its following friendly exchange is a new interaction. Repeating the unchanged interaction still fails. No global repeat-limit removal, diagnostic filter, stats change or EmptyAI substitution is included.

No packet fields, save serialization or RNG APIs change. The new origin/requests/snapshots are transient AI state. Ordered behaviour intentionally changes; bit-identical outcomes across asynchronous schedules or old/new AI are not asserted. Save/load and native gameplay were not executed by this worker. Ordinary lost-hero battle-defeat diagnostics and unrelated AI failures remain outside this correction. Historical failed production logs and failed intermediate test/build receipts remain intact.
