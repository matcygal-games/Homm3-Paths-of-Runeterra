  runeterra-demacia/.venv/Scripts/python.exe -B runeterra-zaun/assets/source/regional-crests-20261025-v4/clean-t1/reproduce.py

This uses frozen paintings, owned whole-pose masks, explicit native registration,
and ordinary current role contracts. It does not need the provider cache, private
session logs, licensed reference PNGs, old guided actions or a 3D tool. Candidate
recipes are written only to assets/candidates/regional-crests-clean-t1-20261025-v1/recipes.

Clean ancestry is recorded in clean-standing-lineage-v1.json. The original standing
base was generated with no image input; the upgraded standing painting referenced
only that base. The new action paintings referenced these clean identities and
inspected original Heroes III references, never old guided action art. Thirteen
actual built-in imagegen calls and exact prompts/receipt hashes are retained in
generation-manifest-v1.json and per-cohort generation records. Their private event
references are history, not public runtime dependencies.

The source inventory selects 104 complete painted pose objects from ten action/
auxiliary cohorts. It explicitly rejects clipped/merged/unused raw poses. In
particular the first base death atlas is not selected, the first upgraded UP attack
row is replaced by a new complete painting, and the base falling transition is
replaced by a new same-orientation painting. No rejected part is reconstructed by
stretching, synthetic appendages, mirroring or translating an idle pose.

Whole-pose isolation retains source RGBA with explicit ownership masks to exclude
adjacent overlapping bounding rectangles. Native assembly uses one uniform scale
per painted action cohort and a fixed contact-root ledger, with no body/limb warp.
The authoritative battle registration is 450x400 with pivot197,266. The historical
role contract body_center175,266 is inconsistent with the actual native front/root
registration; it is preserved as historical metadata, not used to shift the figure.
No content or footprint value was changed.

Each unit has 52 battle slots in the existing action groups, plus independent map,
large/small portraits and left/right attack icons. DEAD is the last death frame.
TURN_R reverses the newly painted TURN_L halfturn, matching inspected original
CPKMAN forward/reverse halfturn semantics around the engine's facing change.
There are real walk, fidget, impact, defend, fall and three directional strike
paintings. No new mechanics, shots, spells, statistics or timing are introduced.

The Zaun respirator is painted onto the existing upper sleeve/shoulder material.
At native size its simplified 6-8px structure and natural occlusion are expected;
it is not an official detailed logo stamped on every frame. Tiny head portraits
naturally crop away that shoulder. Chem-Punk retains stronger scrap protection,
cap/harness, a reinforced pipe head and a contained green belt vial.
