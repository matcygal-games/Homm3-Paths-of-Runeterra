# Baron Nashor and Nashor Pit — painted candidate v1

Status: **authored configuration**. This folder is an unselected source candidate, not native gameplay evidence or release acceptance. No canonical content, selected recipes, stage or desktop is owned by this producer.

The graphics rule followed is: "Use image-based painted sprite production and coherent 2D animation, with the actual original Heroes III assets as the visual authority."

All body pixels come from original project-directed painted 2D imagegen masters. Exact prompts and the own identity-reference chain are preserved. `identity-study-v0.png` is the initial own generated study with cropped outer edges; it is retained only as provenance for the corrected, spacious `motion-v1.png`. No final pose is extracted from that study. Combat, death and portrait creation reference only the corrected own motion master. No Blender, other 3D renderer, third-party art or original troop pixels were used as a generation input. The original native Griffin reference was inspected solely for classic miniature scale, light, perspective and grounding.

`produce_candidates.py` isolates complete painted alpha components without repainting or warping body pixels, registers one fixed scale per master cohort and places each pose on the native pivot. It assembles the actual World compiler twice and rejects deliberately incorrect source/master pins. `freeze_candidates.py` records all source members in explicit lexical POSIX-path order after author pixel inspection.

Candidate identities: `baronNashor` and `nashorPit`. The living, grounded two-hex boss uses ordinary slithering movement as a project adaptation of Riot's Voidborn wyrm. It has a heavy connected legless coil, rearing purple armored neck, multiple magenta eyes, ivory mandibles and foreclaws. No flight, subterranean teleportation, obstacle crossing, acid shooting, regeneration, immunity, spells or siege/global aura is implied. Unique non-recruitable flags, stats and finite rewards belong to the separate mechanics integration.

Six creature roles include genuine coil movement, breathing poses, high/level/low melee bites and claw strikes, reactions, turns, a real neck/body fall and a matching inert corpse. The six-frame idle loop intentionally repeats four unique painted poses. The pit is a separate land object with a visibly open southern entrance; it contains no frozen live Baron figure.

Limitations: native animation timing, battlefield obstruction, combat balance, visiting and reward delivery remain unexecuted. Browser playback is illustrative. No new audio or final art/rights acceptance is asserted.
