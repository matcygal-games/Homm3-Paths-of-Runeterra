# Cloud Drake painted candidates

Complete independent painted candidate with six creature roles and one windy land roost. Seven recipes produce 45 battle frames and native adventure, encounter, portrait and site graphics. No shared content, manifest, stage or release is owned here.

The pale living drake has a compact hawkish head, swept horns and crest, long sickle-shaped membranous wings and a whip tail ending in blade-like scales. Native two-hex flying melee and finite roost cache are project adaptations. No extra attacks, haste aura, slow immunity, magical breath, global soul buff or Targon-exclusive claim is made.

The Cloud-only technical extractor derives from the existing whole-actor alpha component extractor, with atomic PNG publication into the source tree from the outside review directory. Editable painted masters, exact prompts, fixed registration annotations, component records, native frames and checksummed recipes are preserved. Earlier cohorts remain untouched.
