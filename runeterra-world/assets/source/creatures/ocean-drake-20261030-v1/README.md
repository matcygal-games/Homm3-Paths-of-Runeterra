# Ocean Drake painted candidates

Complete painted candidate action set and coastal land roost. Seven recipes produce 45 battle frames and adventure, portrait, encounter and site roles. Actual compiler assembly is deterministic; source/privacy and mutation checks were executed. Independent review and native verification remain separate. No shared content, manifest, stage or release is owned here.

Distinct jade/teal living wyvern with long sinuous neck, narrow head, ivory horns, webbed cheek fins, slender wings and a broad finned tail. Two-hex flying physical-melee handling is a project adaptation. No healing, ranged slowing attack, breath, magical immunity or global soul reward is implemented by this art.
