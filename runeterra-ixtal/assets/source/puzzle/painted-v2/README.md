# Painted puzzle cover revision

The actual first Ixtal cover was too close to a realistic landscape beside the original Heroes III puzzle mural. V2 retains the own Ixtali composition and changes its artistic language to warm outlined sepia relief. The original Castle puzzle was a private style reference, not a source of redistributed pixels or subjects. V1 remains preserved as rejected style history.

`produce.py` is the unchanged technical V1 splitter with versioned filenames. It writes 48 exact crops covering 592x544 without gaps or overlaps, respecting the actual native `CPuzzleWindow` +1 authored-x offset. It draws no final artwork. Native reveal behavior and final human/rights acceptance remain pending.
