# Ixtal painted town source candidate

Status: authored configuration. Genuine built-in imagegen painted2D sources;
no Blender, other3D production or code-drawn final artwork. The shared imagegen
skill was read and used in default built-in mode. Provider model identity is
not exposed by that tool and is not invented here.

The whole-city composition preceded layered production. It is an architectural
source study, not the terrain-only plate. `landscape/` is the separate empty
terrace/background candidate. Thirty-five states share sixteen ordinary sites,
seven paired dwelling sites, one optional river landing and a separate Grail.
Hall4, Guild5 and Fort3 are replacement-state families. `layout-plan-v6.json`
records full maximum envelopes, door approaches, public routes and river bounds;
earlier plans remain unselected history.

Every selected state has a genuine painted master, exact prompt and generation
ledger. `placement-inputs-v1.json` is the hand-authored entrance/physical-scale
calibration input. `assemble.py` performs deterministic whole-source uniform
family scaling, native800x374 registration, masks, one-pixel highlights and
technical campaign/construction crops. No source pose or architecture is painted
by code. Material walls remain opaque; natural openings and contact-shadow alpha
are preserved. Correct official Ixtal crests appear on physical jade cloth and
carved stone, including permanent civic heraldry in early/empty states.

Run from the workspace root with the existing project environment:

```powershell
.\runeterra-demacia\.venv\Scripts\python.exe -B runeterra-ixtal/assets/source/town/painted-v1/assemble.py
```

This authors candidate sources/recipes/reviews only. The coordinator selects the
142 recipes in `candidate-recipes-v1.json` through the existing production CLI.
They cover35 animations,35 areas,35 borders,35 campaign images, the landscape
and ONE native indexed `buildingIcons.json`. Standalone150x70 construction crops
remain editable source inputs; they are not extra live outputs. Actual HALL IDs
come from the unchanged native building library, including index gaps.

All private official/native reference bytes and raw provider receipts stay
outside distributable sources. Public PNGs are clean RGBA encodings with decoded
pixels preserved; actual PNG/JUMBF metadata and source-export privacy admission
are checked separately. Project-relative source/hash ancestry keeps every selected
creative reference reproducible. Original masters and boundary-repair ancestors
are retained rather than overwritten.

The coordinator reviewed the assembled town at native size as a coherent source
composition. That is not a native screenshot, game construction/click test,
external final art approval or redistribution permission. In-memory SDK planning
and repeat byte checks are bounded technical observations; no cold runtime/data
copies, stage publication, desktop operation or release acceptance are claimed.
